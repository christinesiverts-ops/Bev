# Chain Audit Tool: Recommendations

*Prepared 9/26/2026. Plan data comes from the Non-Alc Chain Document (9/8/2026). Structure and missing accounts come from the HW Soda Chain Activity hot sheet (8/25/2025).*

## 1. Summary

**Recommendation: stay on Microsoft 365, but split the tool into two parts.**

| Part | What it holds | Who edits | Who views | Where it lives |
|---|---|---|---|---|
| **The Plan** | Chain Program (hot sheet) and Promo Calendar | Manager only | Whole team, view-only | Excel workbook in SharePoint/OneDrive (`Chain_Audit_Tool.xlsx`) |
| **The Visit Log** | Store checks, discrepancies, notes, follow-ups | Each rep adds their own entries | Whole team (manager sees all) | **Microsoft List** (phase 2). Until then, the Visit Log tab. |

A single live Excel file cannot let reps add notes and still keep them view-only on pricing. In Excel, anyone who can add a row can also overwrite the plan or someone else's notes, and edits aren't clearly tied to one person. Microsoft Lists fixes this at no extra cost on most M365 plans:

- Reps can **create items and edit only items they created**.
- Every entry records **Created By and a timestamp** automatically.
- **Version history** is kept.
- There is a **phone app**.
- You can filter by store to recall prior notes.

## 2. What was built (this repo)

`Chain_Audit_Tool.xlsx` is generated by `tools/build_workbook.py` from `tools/program_data.py`.

| Tab | Purpose |
|---|---|
| **README** | How to use the tool, color key, rep and manager workflows |
| **Dashboard** | KPIs (programs, programs needing confirmation, active and upcoming promos, visits in 30 days, open and overdue issues, price match rate), plus breakdowns by brand, by rep and by discrepancy type |
| **Chain Program** | 42 brand × account programs, using the HW hot-sheet layout (**Channel → Availability → Merchandising → Pricing/Promotion**) plus a new **Execution & Accountability** group. Formulas show Current Promo, **Expected Shelf Price Today**, Next Promo Start, Visits (30d), Open Issues and Last Visit. |
| **Promo Calendar** | 81 dated windows. Status (Active / Upcoming / Expired) is set automatically from today's date. Unit Retail feeds the expected price, and case-cost-only windows are kept separate. |
| **Visit Log** | One row per store check. Reps fill the yellow cells: Rep, Program, Store #, SKU, observed price, tag, planogram location, in-stock, display, discrepancy type, notes, follow-up owner, due date and status. The workbook fills in the expected price as of the visit date and scores the check as Match / Over / Under. |
| **Store History** | Pick a program and store to see today's plan and the **last 20 visit notes, newest first**. This is how notes get recalled on the next visit. |
| **Data Review** | 17 conflicts and gaps found while merging the two documents |
| **Lists** | Dropdowns: team roster, SKUs, discrepancy types, statuses |

## 3. Design changes vs. the current documents

1. **Chain names as text, not logos.** Both source documents identify chains only by logo images, so you can't filter, search, count or look them up. Logos can go back in later as decoration.
2. **One row per brand × account.** The Non-Alc doc groups accounts by brand, and the HW deck groups brands by account. A single keyed table (`Brand | Account`) supports both views through filters and ties every visit to exactly one plan row.
3. **Separate the promo calendar from the hot sheet.** Accounts like WinCo (16 windows) and Rosauers can't fit in one cell. With dated rows, the tool knows what is live **today**, and reps see one expected price instead of reading date ranges.
4. **Separate shelf retail from case cost.** Reps audit shelf retail. Case costs and PTRs belong to the distributor price book. The Non-Alc doc mixes them, for example "$19.55 case cost. Retail TBD."
5. **Standard discrepancy types.** Free-text notes can't be counted. Dropdown types (price over/under, missing tag, expired tag still up, OOS, wrong planogram location, display not built, and so on) drive the dashboard, and notes add the detail.
6. **Accountability fields on every issue:** Follow-up Owner, Due Date, Status and Resolved Date, with overdue items shown in red and rolled up by rep.
7. **Source and data status on every row**, so nobody audits against stale pricing without knowing it.
8. **Keep the field checklist, but make it structured.** The Non-Alc "Field Execution Checklist" (pricing, displays, distribution, follow-up) is now the Visit Log columns.

## 4. Platform options researched

| Option | View-only plan | Reps add own notes | Recall prior notes | Mobile / photos | Extra cost | Effort |
|---|---|---|---|---|---|---|
| **A. Excel only** (today) | Yes, but only by giving reps no edit rights, which blocks notes | Only with edit rights to the whole file | Store History tab | Excel mobile works but is clunky | None | Done |
| **B. Excel plan + Microsoft List visit log** ✅ | Yes (share as *Can view*) | Yes, with item-level "create and edit own items" | Filter the List by store, or the Store History tab | Lists mobile app | **None** on most M365 business plans | Low (about 1 day) |
| **C. B + Power Apps canvas app** | Yes | Yes | App shows plan + last notes on one screen | Best (camera, offline-ish) | None if you stay on SharePoint/Excel standard connectors; Premium is $20/user/mo (rising to $22 on 1/1/2027) | Medium (1–2 weeks) |
| **D. Airtable** | Yes. Read-only users are free on Team/Business. | Yes, through forms or interfaces | Linked records per store | Good | $20/editor/mo (annual) | Medium. New tool, and Airtable was acquired by Bending Spoons in Aug 2026, so pricing may change. |
| **E. Retail execution platform** (Repsly and similar) | Yes | Yes, with GPS check-in and photo audits | Built in | Best. Includes image recognition for shelf audits. | Custom quote, 12-month minimum | High. Worth it at larger team scale. |

**Why B, then C:** your team already works in Word, PowerPoint and Excel, so Microsoft 365 is almost certainly licensed. Lists gives you real view-only / add-only permissions and automatic "who logged this" attribution for $0. A Power Apps front end later gives reps a single phone screen: pick a store, see the expected price and last notes, then log the visit. It needs no premium license as long as it only uses SharePoint and Excel connectors.

**Known Lists caveat:** item attachments ignore item-level permissions, and adding attachments needs edit rights. For store photos, use an **Image column** or a Power Apps camera control rather than the attachments field.

## 5. Roll-out plan

**Phase 1: this week (Excel only)**
1. Put `Chain_Audit_Tool.xlsx` in a SharePoint site or OneDrive folder you own.
2. Work the **Data Review** tab. Load 2026 windows into Promo Calendar and flip programs to "Current (2026)".
3. Fill in the **Lists → Team Roster**, and delete the example row and roster entry.
4. Share the workbook with the team as **Can view**.

**Phase 2: next 2 weeks (Microsoft List for visit notes)**
1. In Microsoft Lists, create a list from the Visit Log columns (`docs/visit_log_list_schema.csv`).
2. Make Program ID a **Choice** or **Lookup** column (paste the Program IDs from Chain Program), and make Rep a **Person** column.
3. List settings → Advanced settings → **Read access: all items; Create and edit access: only their own**.
4. Give reps **Contribute** permission on the List only, and **Read** on the workbook.
5. Build views: *My open items*, *Overdue*, *By store*, *Last 30 days*. Pin the List to a Teams channel.
6. Optional: a Power Automate flow that emails the owner when an item goes past its due date. This uses standard connectors only.

**Phase 3: when the process sticks (Power Apps)**
Build a canvas app over the List and the Chain Program table. The screens are store picker → plan and last-3-notes card → audit form with a camera. Save the expected price into the List row at submit time, so each audit is a **frozen record** even if the plan changes later.

**Revisit option E** if the team grows past roughly 15 reps, or if you need GPS proof-of-visit and photo recognition.

## 6. Accountability model

| Role | Plan (pricing, promos, callouts) | Visit log |
|---|---|---|
| Manager | Edit | Read all, edit all, close items |
| Rep | View only | Add entries; edit only their own |
| Distributor / partner (optional) | View-only link to a filtered export | None |

Weekly manager review (Dashboard):
- overdue follow-ups by rep
- reps with no visits in 30 days
- price match rate
- open discrepancies by type
- Data Review items still open
